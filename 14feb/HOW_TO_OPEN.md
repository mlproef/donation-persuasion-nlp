# 📱 Как открыть сайт

Есть несколько способов открыть сайт для вашей девушки:

## 🚀 Вариант 1: Локальный сервер (рекомендуется)

### Способ 1: Через терминал (самый простой)
1. Откройте **Терминал** (Terminal) на Mac
2. Перейдите в папку с сайтом:
   ```bash
   cd ~/Desktop/Haskel/bsp2/14feb
   ```
3. Запустите сервер:
   ```bash
   python3 -m http.server 8000
   ```
4. Откройте в браузере: **http://localhost:8000**
5. **Не закрывайте окно терминала!** Сервер должен работать

### Способ 2: Двойной клик (для Mac)
1. Просто **дважды кликните** на файл `start_server.command`
2. Откроется терминал и запустится сервер
3. Браузер откроется автоматически

### Способ 3: Через Python скрипт
1. Дважды кликните на файл `start_server.py`
2. Или в терминале:
   ```bash
   cd ~/Desktop/Haskel/bsp2/14feb
   python3 start_server.py
   ```

### Чтобы она могла открыть на своем устройстве:
1. Узнайте IP-адрес вашего компьютера:
   - **Mac/Linux:** `ifconfig | grep "inet "` или `ipconfig getifaddr en0`
   - **Windows:** `ipconfig` (ищите IPv4 адрес)

2. Запустите сервер (как выше)

3. На ее устройстве откройте в браузере: `http://ВАШ_IP:8000`
   Например: `http://192.168.1.100:8000`

4. **Важно:** Оба устройства должны быть в одной Wi-Fi сети!

---

## 🌐 Вариант 2: GitHub Pages (бесплатный хостинг)

1. Создайте репозиторий на GitHub
2. Загрузите все файлы из папки `14feb`
3. В настройках репозитория включите GitHub Pages
4. Сайт будет доступен по адресу: `https://ваш-username.github.io/название-репозитория`

**Плюсы:** Бесплатно, доступно из любой точки мира, не нужно держать компьютер включенным

---

## 📦 Вариант 3: Netlify Drop (самый простой для деплоя)

1. Перейдите на https://app.netlify.com/drop
2. Перетащите всю папку `14feb` в браузер
3. Получите ссылку на сайт (например: `https://random-name-123.netlify.app`)

**Плюсы:** Очень просто, бесплатно, работает сразу

---

## 💾 Вариант 4: Просто открыть файл (самый простой, но может не работать)

1. Просто откройте файл `index.html` двойным кликом
2. Сайт откроется в браузере

**Минусы:** Могут быть проблемы с загрузкой изображений в некоторых браузерах

---

## 📲 Вариант 5: Отправить архив

1. Заархивируйте всю папку `14feb` (ZIP)
2. Отправьте ей архив
3. Она распаковывает и открывает `index.html`

---

## 🎯 Рекомендация

**Для быстрого доступа:** Используйте **Вариант 1** (локальный сервер) - запустите сервер и дайте ей IP-адрес.

**Для постоянного доступа:** Используйте **Вариант 2** (GitHub Pages) или **Вариант 3** (Netlify) - она сможет открыть сайт в любое время по ссылке.

---

## ⚠️ Важные замечания

- Убедитесь, что все изображения находятся в папке `images/`
- Если используете локальный сервер, **не закрывайте терминал** - сервер должен работать
- Для доступа по сети убедитесь, что файрвол не блокирует порт 8000

## 🔧 Если команда не работает:

### Проблема: "python3: command not found"
**Решение:** Попробуйте `python` вместо `python3`:
```bash
python -m http.server 8000
```

### Проблема: "Port 8000 is already in use"
**Решение:** Используйте другой порт (например, 8080):
```bash
python3 -m http.server 8080
```
Тогда откройте: `http://localhost:8080`

### Проблема: Изображения не загружаются
**Решение:** Обязательно используйте локальный сервер (не открывайте файл напрямую)
