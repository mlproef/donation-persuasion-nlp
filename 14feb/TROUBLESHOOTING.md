# 🔧 Решение проблем с доступом к сайту

Если ваш друг не может зайти на сайт с другого устройства, проверьте следующее:

## ✅ Шаг 1: Проверьте IP-адрес

После запуска сервера в терминале будет показан IP-адрес. Убедитесь, что друг использует **именно этот адрес**.

### Как узнать IP-адрес вручную:

**На Mac:**
```bash
ifconfig | grep "inet " | grep -v 127.0.0.1
```

Или:
```bash
ipconfig getifaddr en0
```

**На Windows:**
```bash
ipconfig
```
Ищите IPv4 адрес (обычно начинается с 192.168. или 10.)

---

## ✅ Шаг 2: Проверьте Wi-Fi сеть

**ОБА устройства должны быть в ОДНОЙ Wi-Fi сети!**

- Ваш компьютер и телефон друга должны быть подключены к одной сети
- Если вы на домашнем Wi-Fi, а друг на мобильном интернете - **не сработает**
- Если вы на разных сетях Wi-Fi - **не сработает**

---

## ✅ Шаг 3: Проверьте файрвол

Mac может блокировать входящие соединения. Нужно разрешить доступ:

### На Mac:
1. Откройте **Системные настройки** → **Безопасность и конфиденциальность** → **Файрвол**
2. Нажмите на замок и введите пароль
3. Если файрвол включен, нажмите **Параметры файрвола**
4. Убедитесь, что Python разрешен, или временно отключите файрвол

### Альтернатива - разрешить порт через терминал:
```bash
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add /usr/bin/python3
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --unblockapp /usr/bin/python3
```

---

## ✅ Шаг 4: Проверьте, что сервер запущен правильно

Убедитесь, что в терминале вы видите:
```
🚀 Сервер запущен!
🌐 Доступ с других устройств: http://192.168.X.X:8000
```

Если видите только `localhost` - сервер не доступен извне.

---

## ✅ Шаг 5: Попробуйте другой порт

Если порт 8000 занят или заблокирован, измените порт:

1. Откройте `start_server.py`
2. Измените `PORT = 8000` на `PORT = 8080` (или другой)
3. Перезапустите сервер
4. Друг должен открыть новый адрес: `http://ВАШ_IP:8080`

---

## ✅ Шаг 6: Проверьте на вашем устройстве

Сначала проверьте, что сайт открывается на вашем компьютере:
- Откройте `http://localhost:8000` - должно работать

Затем проверьте с вашего телефона (в той же Wi-Fi сети):
- Откройте `http://ВАШ_IP:8000` - должно работать

Если не работает даже с вашего телефона - проблема в настройках сети/файрвола.

---

## 🎯 Быстрая проверка

Выполните эти команды в терминале:

```bash
# 1. Узнать ваш IP
ifconfig | grep "inet " | grep -v 127.0.0.1

# 2. Проверить, что порт слушается
lsof -i :8000

# 3. Проверить файрвол
/usr/libexec/ApplicationFirewall/socketfilterfw --listapps
```

## 💡 Альтернативные решения

Если ничего не помогает, используйте:

1. **Netlify Drop** - самый простой способ:
   - Перейдите на https://app.netlify.com/drop
   - Перетащите папку `14feb`
   - Получите ссылку, которая работает везде

2. **GitHub Pages** - бесплатный хостинг:
   - Загрузите файлы на GitHub
   - Включите GitHub Pages
   - Получите постоянную ссылку

3. **Отправить архив** - если интернет не нужен:
   - Заархивируйте папку `14feb`
   - Отправьте другу
   - Он распаковывает и открывает `index.html`

---

## ❓ Частые ошибки

**"Сайт недоступен" или "Не удается подключиться"**
→ Проверьте IP-адрес, сеть Wi-Fi и файрвол

**"Сайт открывается, но картинки не загружаются"**
→ Убедитесь, что используется сервер (не просто открыт файл)

**"Порт уже занят"**
→ Измените порт в скрипте на другой (8080, 3000, и т.д.)
