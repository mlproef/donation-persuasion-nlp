# Data

## Source

All dialogs come from the **PersuasionForGood** corpus
(Wang et al., ACL 2019, [paper](https://aclanthology.org/P19-1566/),
[original data](https://gitlab.com/ucdavisnlp/persuasionforgood/tree/master/data),
[ConvoKit version](https://convokit.cornell.edu/documentation/persuasionforgood.html)),
released under the Apache License 2.0.

It contains 1,017 crowd-sourced conversations (20,932 utterances) in which one
participant, the **persuader**, tries to convince the other, the **persuadee**,
to donate part of their task payment to a children's charity. After the chat
both participants privately decide how much to donate.

## Folders

| Folder | Contents | In git? |
|---|---|---|
| `raw/` | Original corpus tables: `full_dialog.csv` (utterances) and `full_info.csv` (participants and donations). Download them from the links above. | No |
| `interim/` | Raw output of the three LLM classifiers in `src/classification/`. Regenerated by running them. | No |
| `processed/` | `full_dialog_with_all_analysis.csv`, the final dataset with every label merged in. | Yes |

## Columns

Column names follow the original corpus.

| Column | Meaning |
|---|---|
| `B2` | Dialog id |
| `B4` | Role: `0` = persuader, `1` = persuadee |
| `Turn` | Turn index inside the dialog |
| `Unit` | Utterance text |
| `B6` | Donation amount in USD (`full_info.csv` only) |
| `strategy_ollama_single` | Task 3: persuasion strategy of a persuader message |
| `sentiment_ollama_v2` | Task 1: `negative` / `neutral` / `positive` for a persuadee message |
| `interest_ollama_v2` | Task 2: `Not Interested` / `Neutral` / `Interested` for a persuadee message |
| `interest_label_ollama_v2` | Task 2 as a number: `0` / `1` / `2` |

A dialog counts as "ended in a donation" when either participant's `B6` is above 0
(`results/donation_dataset_stats.csv`). This is the definition used in every result
in this repository.
