# Документация проекта BSP2

## Обзор проекта

Проект анализирует диалоги убеждения (persuasion dialogues), где один участник (persuader, B4=0) пытается убедить другого (target, B4=1) сделать пожертвование. Проект решает две основные задачи:

1. **Классификация реакций** убеждаемого (отказ/нейтрально/заинтересован)
2. **Определение стратегий убеждения** (40 различных стратегий)
---
## Таблицы данных (CSV файлы)

### Базовые таблицы (созданы первыми)

#### `full_dialog.csv`
**Описание:** Основная таблица со всеми диалогами  
**Структура:**
- `B2` - ID диалога
- `B4` - Роль участника (0 = persuader, 1 = target)
- `Turn` - Номер хода в диалоге
- `Unit` - Текст сообщения

**Использование:** Базовая таблица для всех дальнейших анализов
---
#### `full_info.csv`
**Описание:** Дополнительная информация о диалогах  
**Структура:**
- `B2` - ID диалога
- `B4` - Роль участника
- `B6` - Сумма пожертвования (используется для определения, был ли донат)
**Использование:** Используется для создания сбалансированных выборок (диалоги с донатом vs без доната)

### Таблицы реакций (реакции убеждаемого)

**Структура:**

- `sentiment_reaction` - Реакция по sentiment модели (negative/neutral/positive)
- `mnli_reaction` - Реакция по MNLI модели (contradiction/neutral/entailment)

**Метод:** Использует:
- `cardiffnlp/twitter-roberta-base-sentiment` для sentiment анализа
- `roberta-large-mnli` для проверки гипотез о согласии/отказе

---

#### `reaction_annotation.csv`
**Описание:** Выборка из 500 сообщений для ручной разметки  
**Создано скриптом:** `metki_for_roberta1.py`  
**Структура:**
- `B2`, `Turn` - Идентификаторы
- `text` - Текст сообщения

---

- `label` - Ручная метка: 0=отказ, 1=нейтрально, 2=заинтересован

- `B2`, `Turn` - Идентификаторы

**Описание:** Сбалансированная выборка для разметки (по донатам)

## Скрипты (Python файлы)

### Базовые скрипты (созданы первыми)

#### `bsp2.py`
**Описание:** Первый скрипт для анализа реакций  
**Что делает:**
1. Загружает `full_dialog.csv`
2. Для сообщений target (B4=1) вычисляет:
   - `sentiment_reaction` через RoBERTa sentiment модель
   - `mnli_reaction` через RoBERTa-large-MNLI (проверяет гипотезу "The person agrees with the request")
3. Сохраняет результат в `full_dialog_with_reactions.csv`

**Модели:**
- `cardiffnlp/twitter-roberta-base-sentiment`
- `roberta-large-mnli`

---

#### `bsp2_first_roberta_for_strategies.py`
**Описание:** Первая попытка определения стратегий убеждения  
**Что делает:**
1. Загружает `full_dialog.csv`
2. Оставляет только сообщения persuader (B4=0)
3. Использует zero-shot классификатор `facebook/bart-large-mnli`
4. Определяет до 4 стратегий для каждого сообщения (45 возможных стратегий)
5. Сохраняет в `strategies_B4_0.csv`

**Особенности:**
- Использует pipeline из transformers
- Минимальный порог score = 0.30
- Возвращает до 4 стратегий через запятую

---

#### `bsp_new_clasificator_for_willing.py`
**Описание:** Создание калибратора для реакций на основе MNLI признаков  
**Что делает:**
1. Загружает размеченные данные `reaction_annotation_labeled1.csv`
2. Для каждого примера вычисляет 4 MNLI признака:
   - p_agree: "The person agrees with the request"
   - p_will_donate: "The person says they will donate money"
   - p_interested: "The person is interested in the donation"
   - p_refuse: "The person refuses to donate any money"
3. Обучает LogisticRegression на этих признаках
4. Сохраняет модель в `reaction_calibrator.joblib`

**Метод:** Использует MNLI entailment вероятности как признаки для классификатора

---

#### `bsp_adding_b0_b4.py`
**Описание:** Объединение стратегий с полным диалогом  
**Что делает:**
1. Загружает `full_dialog.csv` и `strategies_B4_0.csv`
2. Берет только первую (лучшую) стратегию из списка
3. Объединяет с полным диалогом
4. Сохраняет в `full_dialog_with_strategies_top1.csv`

**Результат:** Полный диалог с одной стратегией для каждого сообщения persuader

---

#### `bsp2_my_roberta_for_strategies.py`
**Описание:** Финальная версия определения стратегий с контекстом  
**Что делает:**
1. Загружает `full_dialog.csv`
2. Для каждого сообщения persuader (B4=0):
   - Строит контекст из последних 4 сообщений диалога
   - Проверяет 40 стратегий через roberta-large-mnli
   - Выбирает лучшую стратегию (если score >= 0.30)
3. Сохраняет в `full_dialog_with_nli_strategies.csv`

**Отличия от первой версии:**
- Использует контекст диалога (не только текущее сообщение)
- 40 стратегий вместо 45
- Использует roberta-large-mnli напрямую (не pipeline)
- Возвращает только одну лучшую стратегию

**Стратегии:** 40 различных стратегий убеждения (Rewarding Activity, Emotional Appeal, Social Proof, и т.д.)

### Скрипты для применения моделей

#### `apply_reaction_calibrator.py`
**Описание:** Применение калибратора ко всем сообщениям target  
**Что делает:**
1. Загружает `full_dialog.csv` и обученный `reaction_calibrator.joblib`
2. Для всех сообщений target (B4=1):
   - Вычисляет 4 MNLI признака
   - Применяет калибратор для получения метки 0/1/2
3. Сохраняет в `full_dialog_with_calibrated_reactions.csv`

**Результат:** Все диалоги с откалиброванными реакциями

---

#### `apply_roberta_classifier.py`
**Описание:** Применение fine-tuned RoBERTa модели для классификации реакций  
**Что делает:**
1. Загружает обученную модель из `./roberta_reaction_classifier/best_model`
2. Загружает `full_dialog.csv`
3. Для каждого сообщения target:
   - Строит контекст (2 предыдущих сообщения)
   - Делает предсказание через fine-tuned модель
   - Сохраняет метку и вероятности
4. Сохраняет в `full_dialog_with_roberta_reactions.csv`

**Модель:** Fine-tuned RoBERTa на размеченных данных с контекстом

---

### Скрипты для обучения моделей

#### `finetune_roberta_context.py`
**Описание:** Fine-tuning RoBERTa для классификации реакций с контекстом  
**Что делает:**
1. Загружает `reaction_annotation_labeled_with_context.csv`
2. Разделяет на train/val/test (60/20/20)
3. Обучает RoBERTa-base на контекстах диалогов
4. Сохраняет лучшую модель в `./roberta_reaction_classifier/best_model`
5. Оценивает на test set

**Параметры:**
- Модель: `roberta-base`
- Max length: 512
- Batch size: 8
- Learning rate: 2e-5
- Epochs: 5

**Метрики:** Accuracy, Precision, Recall, F1

## 📝 Примечания

### Метки реакций
- **0** = отказ (refusal)
- **1** = нейтрально (neutral)
- **2** = заинтересован (interested)

### Роли участников
- **B4 = 0** = persuader (убеждающий)
- **B4 = 1** = target (убеждаемый)

### Модели
- **RoBERTa-large-MNLI**: Для проверки гипотез (entailment)
- **RoBERTa-base-sentiment**: Для анализа тональности
- **RoBERTa-base (fine-tuned)**: Для классификации реакций с контекстом
- **BART-large-MNLI**: Для zero-shot классификации стратегий
